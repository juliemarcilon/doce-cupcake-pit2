# 🧁 Doce Cupcake — Loja Virtual (PIT II)

Projeto Integrador Transdisciplinar em Engenharia de Software II — Cruzeiro do Sul Virtual.

## Arquitetura e Tecnologias
- **Padrão Arquitetural:** MVC (Model-View-Controller)
- **Back-end:** Python 3 + Flask
- **Front-end:** HTML5, CSS3, Bootstrap 5
- **Banco de Dados:** SQLite
- **Testes Unitários:** Pytest

## Estrutura do Repositório
- `/docs`: Documentação do PIT I revisada, Diagrama de Classes e Dicionário de Dados.
- `/database`: Script SQL de criação do banco de dados (`database.sql`).
- `/src`: Código-fonte da aplicação web, templates HTML e testes automatizados.
